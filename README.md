# Polymorphic-Engine

A simple polymorphic decryptor-stub generator for Linux x86-64, written in C.

Give it a payload, and it generates a small stub that decrypts the payload
in memory and runs it. The generated bytes are different every build.

---

## What it does

- Picks a random set of registers for the stub each build
- Picks a random encoding (XOR or ADD/SUB) each build
- Encrypts the payload so no plaintext strings appear on disk
- Wraps everything into a static ELF64 executable that runs

## What it does NOT do

- Does not stop memory scanners (payload is plaintext while running)
- Does not stop debuggers, ptrace, or strace
- Does not stop behavioral analysis
- Does not vary the instruction sequence, only the bytes
- Does not use real encryption (single-byte key)

---

## Build

    make

This builds:

    Polymorphic_engine.out
    elf_warp.out

## Use

    ./Polymorphic_engine.out              # writes output.bin
    ./elf_warp.out output.bin output.elf  # wraps into ELF64
    ./output.elf                          # runs

---

## Files

    engine.c                  stub generator
    helper.c                  byte emitters
    keystream_allocation.c    key buffer from /dev/urandom
    keystream_free.c          wipe + free key
    securebzero.c             safe memory wipe
    elf_wrap.c                output.bin -> ELF64
    main.c                    demo
    api.h                     shared header
    Makefile                  build

---

## Limitations

- Linux x86-64 only
- Single-byte key
- Static trailer magic is a fingerprint (easy to find)
- Needs permissive mprotect (RWX or W->X allowed)
- Fixed instruction shape, only bytes change

---

## Scope

This is a byte-level polymorphism demo. It evades basic file signature
scanning only. It is not a packer, not a crypter, and not malware. Do not
use it as one.
